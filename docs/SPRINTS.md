# Sprint plan

Total budget: 16 hours. Planned: about 14 hours, with buffer.

| Sprint | Focus | Hours | Exit criteria |
|---|---|---|---|
| Sprint 1 | Data and analysis core | ~6 | Clean January 2026 datasets, decision-time forecast selector and metrics module, with passing tests |
| Sprint 2 | API and frontend | ~5.5 | FastAPI endpoints and three React views working locally against the real data |
| Sprint 3 | Packaging, deploy, docs, video | ~3.5 | Dockerised, deployed, README complete, video recorded, form submitted |

## Definition of done (every issue)

- Code merged to `main` through a pull request or a direct commit with a clear message
- Tests added for logic changes
- README or docs updated where behaviour changes

## Submission checklist

- [ ] Public repo with anonymous name and complete README
- [ ] Deployed app link in README, opened in incognito
- [ ] Unlisted YouTube video, 10 minutes or less
- [ ] Microsoft form submitted
